## About Me

I'm an **AI Engineer** and **Robotics Instructor** working at the intersection of machine learning,
embedded systems, and applied data science. I build and train models in PyTorch and TensorFlow, and
I teach students to design, assemble, and program robots from the ground up.

**Role:** AI Engineer | Robotics Instructor at FireflyIO

**Core stack:** Python, JavaScript, Node.js, SQL, PyTorch, TensorFlow, MATLAB, Bash

**Hardware:** Microcontrollers, sensors, circuits, 3D modelling and printing

**Currently:** Bridging machine learning and physical robotics

**Open to:** AI/ML Engineering, Data Science, and Robotics roles

What I spend my time on:

- Designing and building robots end-to-end: mechanical assembly, electronics, and Python control code
- Training and evaluating machine learning models with PyTorch and TensorFlow
- Modelling parametric parts in CAD and 3D printing production-ready robotics enclosures
- Teaching robotics, electronics, and programming to students at every level
- Working daily in Ubuntu Linux, VS Code, and Git

Ask me about robotics education, sensor integration, or getting started in machine learning.
